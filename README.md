# Tính điện tử viễn thông

Ứng dụng web tập hợp các phép tính kỹ thuật cơ bản liên quan đến **điện tử và viễn thông**, phục vụ học tập và thực hành.

## Cấu trúc

```text
tinh-dien-tu-vien-thong/
├── index.html
├── script.js
├── styles.css
└── README.md
```

## Thành phần

- `index.html`: giao diện.
- `script.js`: xử lý tính toán và tương tác.
- `styles.css`: định dạng giao diện.

## Mục đích

Cung cấp công cụ tính nhanh các đại lượng kỹ thuật ngay trên trình duyệt.

> Mã nguồn hiện có được giữ nguyên; chỉ cập nhật README.
