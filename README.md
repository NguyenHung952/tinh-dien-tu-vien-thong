# 📐 Tính điện tử viễn thông

> Bộ công cụ web cho các **phép tính kỹ thuật điện tử – viễn thông**, phục vụ học tập, tra cứu và kiểm tra nhanh.

## ✨ Tổng quan

Project tập trung vào việc đưa các phép tính kỹ thuật thường gặp lên giao diện web, giúp thao tác nhanh thay vì tính thủ công từng bước.

## 🧱 Cấu trúc

```text
tinh-dien-tu-vien-thong/
├── index.html      # Giao diện
├── script.js       # Logic tính toán
├── styles.css      # UI
└── README.md
```

## 🚀 Chạy

Mở `index.html` bằng trình duyệt hiện đại hoặc sử dụng static web server.

## 🛠️ Công nghệ

`HTML5` · `CSS3` · `JavaScript`

## 🎓 Mục đích

- Hỗ trợ học các đại lượng kỹ thuật.
- Kiểm tra nhanh kết quả tính toán.
- Thực hành xây dựng công cụ kỹ thuật bằng JavaScript.

**Engineering Calculator / Learning Project** — chỉ chuẩn hóa README, không thay đổi logic hiện có.
